# Copilot Instructions

## Styling
- This project uses **Tailwind CSS v4** with Flowbite React
- Do NOT use Tailwind v3 syntax (e.g. use `@import "tailwindcss"` not `@tailwind base`)
- Prefer utility classes over custom CSS
- Use responsive prefixes (sm:, md:, lg:) for all layout decisions
- Dark mode is handled via the `dark:` variant
