Mockdin Social

🎨 Color System Breakdown (Applied to Mockdin)
🔵 Primary — #4F46E5 (Indigo)

Role: Brand + primary actions

Use this for anything that represents intent or identity:

Logo / app name (“Mockdin”)
Primary buttons:
“Post”
“Sign up”
“Log in”
Active states:
Selected sidebar item (Feed, Profile, Friends)
Links (hover state especially)

👉 Example:

“Post” button → solid indigo background + white text
Active nav item → indigo icon + subtle background tint

---

🟢 Secondary — #22C55E (Green)

Role: Positive feedback / social interaction

Use this where the user feels rewarded:

Like button (active state)
Success messages:
“Account created successfully”
Confirmation states:
“Friend request accepted”
Subtle counters:
Number of likes (optional)

👉 Example:

Heart/like icon → gray → turns green when clicked
Toast message → green accent bar on the left

---

🟡 Accent — #F59E0B (Amber)

Role: Attention without urgency

Use this sparingly to draw the eye:

Notifications badge
“New” indicators
Highlighted UI elements
Demo-related hints:
“Try the Demo User”

👉 Example:

Notification bell → small amber badge with number
“Demo User” button → outline with amber hover

---

⚪ Background — #F9FAFB

Role: Page canvas

Entire app background
Keeps UI light and breathable

👉 Important:
Avoid pure white for the whole page—this off-white reduces eye strain and looks more modern.

---

⚪ Surface — #FFFFFF

Role: Content containers

Use for anything that sits on top of the background:

Post cards
Comment boxes
Navbar
Modals
Input fields

👉 Example:
Each post = white card with shadow over #F9FAFB

---

⚫ Text — #111827

Role: Primary readability

Post content
Usernames
Headings
Important labels

👉 This should dominate your UI text.

---

⚫ Muted Text — #6B7280

Role: Secondary information

Timestamps (“2h ago”)
Placeholder text
Less important metadata
Subtitles

👉 Example:

Username → dark
“posted 3 min ago” → muted gray
